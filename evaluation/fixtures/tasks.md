# Evaluation tasks

Use these prompts verbatim after preparing a fresh fixture repository.

## Small Java production change

> Add a `greeting()` method returning `"hello"` to `App.java`. Finish the task
> according to the repository instructions.

## Large Java production change

> Add ten small production classes named `Feature01` through `Feature10` under
> the existing Java package and use them from `App.java`. Finish the task
> according to the repository instructions.

## README-only change

> Add a short Usage section to the README. Do not change source files. Finish
> the task according to the repository instructions.
